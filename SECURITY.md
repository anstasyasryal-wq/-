# Security Policy

## Supported Versions

Only the latest available version of this project is currently supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to the project maintainer.

Do not publish vulnerability details in public GitHub Issues or social media before the issue has been investigated.

Please include a description of the issue, steps to reproduce it, and its potential impact. Do not include passwords, private user data, access tokens, or other sensitive information.

For private reporting, use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the project maintainer through an established private communication channel.

## Response and Resolution

Reports will be reviewed as soon as reasonably possible. The maintainer will assess the risk, investigate the issue, and work on a fix or mitigation when appropriate.

Response and resolution times may vary depending on the severity and complexity of the issue.

## Responsible Disclosure

Please avoid accessing, modifying, or exposing other users' data, and do not disrupt the service during security testing.

Thank you for helping keep this project and its community safe.
